# 車と免許の期限（kuruma-kigen）

仮免許・国外運転免許証・免許の更新・うっかり失効したときの受け直し、乗用車やトラック・軽自動車の車検、引っこしや名義変更の登録、車庫の場所を変えたときの届け出などの場面を読んで、その期限（15日・1か月・3か月・6か月・1年・2年・3年）を当てる1日5問の学習ゲーム。正解したら、どのきまりか（運転免許／車検／登録と届け出）も選ぶ。車と免許のきまりの学習に。

遊ぶ: <https://satou-aaaaa.github.io/kuruma-kigen/>

- 中身は e-Gov 法令検索の道路交通法（<https://laws.e-gov.go.jp/law/335AC0000000105>）第87・97条の2・100条の2・101・107条の8、道路運送車両法（<https://laws.e-gov.go.jp/law/326AC0000000185>）第12・13・15・61・67・69条、自動車保管場所法（<https://laws.e-gov.go.jp/law/337AC0000000145>）第7条に書いてある期限だけです（2026-11-18 に読んだ今の条文）。
- 説明は条文を、短く言いかえたものです。免許証の有効期間、違反や点数、手数料・税、政令や省令の細かい例外は省いています。公式の情報の代わりではありません。実際のことは、警察や運輸支局の案内、専門家に確かめてください。
- 2段目は、きまりの種類で分けています。
